# Лабораторна робота №1 — реалізація та перевірка backpropagation

## Мета

Реалізувати зворотне поширення похибки **вручну у NumPy**, перевірити градієнти за допомогою PyTorch autograd і центральних скінченних різниць, а також показати, як ці перевірки виявляють навмисну помилку.

## Запуск

Python **3.12**, NumPy, PyTorch (CPU), scikit-learn; обчислення — `float64`.

```powershell
uv sync --locked
uv run --locked python main.py
uv run --locked python main.py --buggy
```



У проєкті **один Python-файл — `main.py`**. Його функції виконуються послідовно: `prepare_data()` → `init_params()` → `forward()` → `backward()` → `torch_reference()` і `numerical_checks()`.

## 1. Дані та ініціалізація

`sklearn.datasets.load_iris()` містить 150 об'єктів, 4 числові ознаки і 3 класи. У `prepare_data()` створюється `np.random.default_rng(0)`. Для класів **0, 1, 2** індекси перемішуються по черзі; перші 35 індексів кожного класу потрапляють у train, решта 15 — у test. Отже, `X_train.shape == (105, 4)`, `X_test.shape == (45, 4)`.

Стандартизація виконується **лише за статистиками train**:

$$
\mu_j=\frac{1}{105}\sum_{i=1}^{105}x_{ij},\qquad
\sigma_j=\sqrt{\frac{1}{105}\sum_{i=1}^{105}(x_{ij}-\mu_j)^2},\qquad
x'_{ij}=\frac{x_{ij}-\mu_j}{\sigma_j}.
$$

Використано `ddof=0`; для test застосовуються ті самі `mean` і `std`.

Архітектура: **Linear(4,8) → ReLU → Linear(8,3)**. Новий незалежний `np.random.default_rng(0)` генерує спочатку $W_1$, потім $W_2$:

| Параметр | Розмір | Початкова ініціалізація |
|---|---|---|
| $W_1$ | 4 × 8 | $\mathcal N(0,2/4)$, стандартне відхилення $\sqrt{2/4}$ (He) |
| $b_1$ | 8 | Нулі |
| $W_2$ | 8 × 3 | $\mathcal N(0,2/11)$, стандартне відхилення $\sqrt{2/11}$ (Xavier) |
| $b_2$ | 3 | Нулі |

Тут другим параметром нормального розподілу записано **дисперсію**, а в `rng.normal(scale=...)` передано її квадратний корінь — **стандартне відхилення**. Усього 67 скалярних параметрів.

## 2. Прямий прохід і функція втрат

Для всіх 105 навчальних об'єктів:

$$
Z_1=XW_1+b_1,\qquad A_1=\max(0,Z_1),\qquad Z_2=A_1W_2+b_2.
$$

$Z_2$ — **логіти** трьох класів. Стабільний log-softmax обчислюється зі зсувом $m_i=\max_k Z_{2,ik}$:

$$
\log P_{ik}=(Z_{2,ik}-m_i)-\log\sum_j\exp(Z_{2,ij}-m_i).
$$

Середня крос-ентропія:

$$
\mathcal L=-\frac1N\sum_{i=1}^N\log P_{i,y_i},\qquad N=105.
$$

Значення, збережені для backward:

| Масив | Розмір | Навіщо потрібен |
|---|---|---|
| $X$ | 105 × 4 | Градієнт першої матриці ваг |
| $Z_1$ | 105 × 8 | Маска похідної ReLU |
| $A_1$ | 105 × 8 | Градієнт другої матриці ваг |
| $Z_2$ | 105 × 3 | Логіти для функції втрат |
| $P$ | 105 × 3 | Початковий сигнал backpropagation |

## 3. Ручний зворотний прохід

Нехай $Y$ — one-hot матриця правильних класів, $\odot$ — поелементний добуток. Правило ланцюга для крос-ентропії, лінійних шарів і ReLU дає:

$$
\begin{aligned}
\Delta_2&=(P-Y)/N && (105\times3),\\
\nabla_{W_2}\mathcal L&=A_1^T\Delta_2 && (8\times3),\\
\nabla_{b_2}\mathcal L&=\sum_i\Delta_{2,i} && (3,),\\
\Delta_1&=(\Delta_2W_2^T)\odot\mathbf{1}_{Z_1>0} && (105\times8),\\
\nabla_{W_1}\mathcal L&=X^T\Delta_1 && (4\times8),\\
\nabla_{b_1}\mathcal L&=\sum_i\Delta_{1,i} && (8,).
\end{aligned}
$$

Для ReLU в точці 0 прийнята похідна 0. **Ділення на $N$ виконується один раз** у $\Delta_2$: усі наступні вирази вже містять потрібний масштаб. Автоматичне диференціювання у NumPy не використовується.

## 4. Перевірка PyTorch autograd

Створено еквівалентну мережу `torch.nn.Sequential` у `torch.float64`. Матриці NumPy копіюються з транспонуванням: PyTorch зберігає ваги шару як `(out, in)`. Використано `torch.nn.functional.cross_entropy(..., reduction="mean")` і `loss.backward()`.

Порівняно **всі 67 елементів чотирьох градієнтів** і значення loss. Критерій для кожного числа: $|a-b|\le10^{-12}$, без відносного допуску. Усі значення скінченні.

Loss NumPy: **1.4562007801142816**; Loss PyTorch: **1.4562007801142818**.

| Величина | Найбільша абсолютна різниця | Перевірку пройдено |
|---|---:|---|
| Loss | 2.2204460492503131e−16 | Так |
| $\nabla W_1$ | 2.7755575615628914e−17 | Так |
| $\nabla b_1$ | 3.2959746043559335e−17 | Так |
| $\nabla W_2$ | 1.1102230246251565e−16 | Так |
| $\nabla b_2$ | 1.5265566588595902e−16 | Так |

## 5. Чисельне диференціювання

Для кожного з чотирьох заданих параметрів, зберігаючи всі інші незмінними, обчислено:

$$
g_{\mathrm{num}}=\frac{\mathcal L(\theta_i+\varepsilon)-\mathcal L(\theta_i-\varepsilon)}{2\varepsilon},\qquad \varepsilon=10^{-6}.
$$

Перед кожним збуренням використовуються **початкові ваги і 105 об'єктів**, після нього змінений параметр відновлюється. Перевірено, що маска ReLU не змінюється. Критерій: $|g_{\mathrm{num}}-g_{\mathrm{manual}}|\le10^{-7}$.

| Параметр | Градієнт backward | Чисельна похідна | Абс. різниця | Пройдено |
|---|---:|---:|---:|---|
| $W_1[0,0]$ | −1.992018433056e−02 | −1.992018439090e−02 | 6.034272734268e−11 | Так |
| $b_1[0]$ | −7.056611158438e−02 | −7.056611162071e−02 | 3.632683043264e−11 | Так |
| $W_2[0,0]$ | 1.352302086055e−01 | 1.352302086977e−01 | 9.218040220027e−11 | Так |
| $b_2[0]$ | 8.552164484196e−02 | 8.552164498798e−02 | 1.460289805744e−10 | Так |

## 6. Дослід із навмисною помилкою

**Прогноз до запуску:** якщо у `backward()` прибрати ділення на $N=105$ з $\Delta_2$, але **не змінювати loss**, то значення втрати не зміниться, усі ненульові градієнти збільшаться у 105 разів, а порівняння з PyTorch та чисельні перевірки виявлять помилку.

Для відтворення: `uv run --locked python main.py --buggy`. Використовуються ті самі початкові параметри, той самий train; PyTorch і формула скінченних різниць не змінюються. Оновлення ваг відсутнє. У правильній версії за замовчуванням ділення на $N$ присутнє.

**Фактичний результат:** loss залишився **1.4562007801142816**, масштаб усіх чотирьох масивів градієнтів збільшився у 105 разів. Усі чотири перевірки градієнтів проти PyTorch та всі чотири чисельні перевірки показали **FAIL**, тобто виявили навмисну помилку. Перевірка loss залишилася **PASS**. Команда `--buggy` завершується успішно саме тоді, коли отримано очікувані відмови; правильний запуск проходить усі перевірки.

## Висновки

Реалізовано прямий прохід двошарової мережі, стійку крос-ентропію та ручне зворотне поширення похибки. Збіг із PyTorch autograd і чотирма чисельними похідними підтвердив коректність реалізації. Експеримент із пропуском $1/N$ показав, що навіть за незмінного loss помилку в градієнтах можна надійно виявити незалежними перевірками.
